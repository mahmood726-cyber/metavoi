Verify in R

Recomputes every number this page displays, in R, from the inputs of the last Compute VoI. Base R regenerates the page's seeded xoshiro128** draws exactly, so the page and R must agree to 1e-9; the script then cross-checks against the normal–normal closed forms and, where installed, voi, BCEA and metafor. Each line prints page value, R value, difference and MATCH or MISMATCH. The full run takes about 25 s in desktop R and one to two minutes in WebR (the Bayesian bootstrap regenerates 25 million uniforms). 

Run a VoI analysis, then download the R script or verify in R here.
